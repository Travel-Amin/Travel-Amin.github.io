# Travel Amin – موقع ثابت (Static) | سایت ثابت

سایت معرفی خدمات گردشگری و سفر درمانی در ایران برای مخاطبان عرب‌زبان؛ **بدون بک‌اند و بدون پایگاه داده**.
کاربر خدمات را می‌بیند و با یک کلیک (یا فرم کوتاه) وارد گفتگوی واتساپ می‌شود.

## ساختار پروژه

```
index.html            صفحه اصلی (عربی، پیش‌فرض)
en/index.html         نسخه‌ی انگلیسی (LTR، همان ساختار و همان idها)
404.html              صفحه خطا
assets/css/style.css  استایل‌ها
assets/js/config.js   ⭐ تنظیمات (شماره واتساپ، تلگرام، آدرس Worker نرخ ارز)
assets/js/lang.js     متن‌های پویا برای هر زبان (عربی/انگلیسی) بر اساس <html lang>
assets/js/main.js     منطق سایت (منو، فرم واتساپ، کارت‌ها، تم تیره)
assets/js/intro.js    صفحه‌ی لودینگ (پرواز + مهر پاسپورت)
assets/js/rates.js    نرخ ارز
assets/fonts/         فونت‌های Tajawal و Plus Jakarta Sans (میزبانی روی همین سایت، woff2)
assets/img/           تصاویر
worker/rates-worker.js  Cloudflare Worker برای خواندن نرخ از TGJU
_headers              هدرهای امنیتی و کش (Cloudflare Pages / Netlify؛ GitHub Pages نادیده می‌گیرد)
llms.txt / robots.txt / sitemap.xml   سئو و معرفی سایت به موتورهای جستجو و هوش مصنوعی
.github/workflows/    انتشار خودکار روی GitHub Pages
```

## تغییر تنظیمات

فقط فایل `assets/js/config.js` را ویرایش کنید:

- `whatsapp`: شماره‌ی واتساپ بدون `+` و صفر (مثال: `989395464608`)
- `telegram`: لینک کانال تلگرام
- `rates.proxy`: آدرس Worker شما

> شماره‌ی واتساپ و آدرس Worker **عمداً عمومی** هستند (روی سایت دیده می‌شوند). هیچ کلید، توکن یا رمزی در این پروژه وجود ندارد و نباید هم قرار داده شود.

## نسخه‌بندی فایل‌ها (کش)

فایل‌های JS و CSS نام ثابت دارند. بعد از هر تغییر در آن‌ها، مقدار `?v=...` را در `index.html`، `en/index.html` و `404.html` عوض کنید (مثلاً تاریخ روز)، وگرنه بازدیدکنندگان ممکن است نسخه‌ی قدیمی را ببینند.

## انتشار روی GitHub Pages

1. یک مخزن (Repository) بسازید و همه‌ی فایل‌ها را در شاخه‌ی `main` بگذارید.
2. در **Settings → Pages → Build and deployment → Source** گزینه‌ی **GitHub Actions** را انتخاب کنید.
3. با هر `push` سایت خودکار منتشر می‌شود (`.github/workflows/pages.yml`).
4. دامنه‌ی اختصاصی: در همان بخش Pages دامنه را وارد کنید و در DNS رکورد CNAME بسازید.

## انتشار روی Cloudflare Pages (پیشنهادی)

GitHub Pages **هدر امنیتی** پشتیبانی نمی‌کند، اما Cloudflare Pages فایل `_headers` را اجرا می‌کند
(CSP کامل، HSTS، جلوگیری از iframe و …).

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git
2. Build command را خالی بگذارید و Output directory = `/`
3. دامنه را وصل کنید (SSL خودکار است).

## نرخ ارز (Worker)

مرورگر مستقیم از TGJU نمی‌تواند بخواند (CORS)، پس `worker/rates-worker.js` را روی Cloudflare Workers قرار دهید.
`ALLOWED_ORIGINS` همان فایل فعلاً فقط `https://travel-amin.github.io` را دارد. وقتی دامنه‌ی اختصاصی وصل شد، آن را هم به لیست اضافه کنید و Worker را دوباره Deploy کنید.
اگر نام Worker را عوض کردید، آدرس جدید را در `config.js`، متای CSP در `index.html`، `en/index.html` و `404.html` و فایل `_headers` به‌روز کنید.

## امنیت

- **CSP سخت‌گیرانه:** فقط اسکریپت و استایل همین سایت اجرا می‌شود (بدون `unsafe-eval` و بدون `unsafe-inline`)؛
  تنها استثنا یک اسکریپت کوچک درون‌خطی برای اعمال تم پیش از رندر است که با هش `sha256` در CSP مجاز شده.
  اگر متن آن را تغییر دادید، هش را دوباره حساب کنید و در متای CSP هر سه فایل به‌روز کنید.
  فقط به Worker نرخ ارز درخواست شبکه می‌رود.
- بدون کوکی، بدون ردیاب، بدون ارسال داده‌ی کاربر به سرور. اطلاعات فرم فقط برای ساخت لینک واتساپ در مرورگر استفاده می‌شود.
- متن‌های فرم پاک‌سازی و کوتاه می‌شوند (حذف نویسه‌های کنترلی و هدایت‌کننده‌ی متن).
- لینک‌های خارجی با `rel="noopener noreferrer"`.
- فونت‌های Tajawal و Plus Jakarta Sans روی همین سایت میزبانی می‌شوند (`assets/fonts/`) و فقط زیرمجموعه‌های عربی/لاتین بارگذاری می‌شوند؛ هیچ درخواستی به سرورهای گوگل نمی‌رود.
- برای سرعت: تصویر اصلی و فونت اصلی با `preload` می‌آیند، اسکریپت‌ها `defer` هستند و تصاویر ابعاد مشخص دارند (جلوگیری از پرش چیدمان).
- تصاویر با `<picture>` سه فرمت دارند: AVIF → WebP → JPEG (هر مرورگر سبک‌ترین فرمت پشتیبانی‌شده را می‌گیرد). فایل‌های JPEG فالبک را نگه دارید و حذف نکنید.

### صفحه‌ی لودینگ

انیمیشن ورود (پرواز + مهر پاسپورت) فقط در اولین بازدید هر نشست، با دکمه‌ی «تخطي»، و حدود ۲ ثانیه نمایش داده می‌شود (برای سرعت بارگذاری کوتاه شده است). اگر کاربر «کاهش حرکت» را در سیستم فعال کرده باشد، اصلاً نمایش داده نمی‌شود. مدت پرواز در `assets/js/intro.js` (متغیر `T`) قابل تغییر است؛ اگر آن را طولانی کردید، مقدار `4000` در اسکریپت درون‌خطی تم داخل `index.html` را هم بزرگ کنید.

### قبل از هر commit
هرگز این‌ها را commit نکنید: فایل `.env`، کلید API، توکن، رمز، اطلاعات پزشکی یا شخصی مشتریان.

## زبان‌ها (عربی و انگلیسی)

- عربی صفحه‌ی اصلی است (`/`) و انگلیسی در `/en/` قرار دارد. هر دو صفحه‌ی کامل و جدا هستند (برای سئو و `hreflang`).
- دکمه‌ی تغییر زبان (EN / عربي) کنار دکمه‌ی حالت شب در هدر است و بخش فعلی صفحه (`#...`) را حفظ می‌کند. انتخاب زبان در مرورگر یادآوری می‌شود.
- هر متنی را که در `index.html` عوض می‌کنید، در `en/index.html` هم عوض کنید (و برعکس). متن‌های پویا (پیام واتساپ، خطاهای فرم، ماه‌ها) در `assets/js/lang.js` و `config.js` هستند.
- فونت انگلیسی Plus Jakarta Sans است و فقط در صفحه‌ی انگلیسی استفاده می‌شود (هر دو فونت در `assets/fonts/` هستند).
- هنگام وصل کردن دامنه‌ی اختصاصی: آدرس‌های `canonical` و `hreflang` در هر دو صفحه و `sitemap.xml` را عوض کنید.
